# egl-util-cpp v1.0.0

**Date:** 2026-07-05 · **SemVer:** 1.0.0 (first stable release)

The first stable release of `egl-util-cpp` — a header-only C++20 toolkit for high-performance
systems, with an optional compiled tier for the OS-boundary components. Milestones 1–10 are
complete, the public API is frozen, and the full enterprise quality bar is green.

## Highlights

- **25 components** across seven modules, all under `it::d4np::util`:
  - **Foundations** — compile-time type traits, constexpr hashing (FNV-1a, MurmurHash3, SHA-256).
  - **Memory** — `UniqueRef`, `HeapArray`, `StackAllocator`, `ObjectPool`.
  - **Containers** — `FlatSet`, `FlatMap`, `CircularBuffer`.
  - **Strings** — `StringSplitter`, `StringBuilder`, `StringFormatter`.
  - **Concurrency** — `Semaphore`, `ReaderWriterLock`, `TaskFuture`, `LockFreeQueue`, `ThreadPool`.
  - **Diagnostics** — `Stopwatch`, `StackTrace`, `Logger`.
  - **Parsing** — `CliParser`, `JsonParser`.
  - **I/O & networking** — `FileStream`, `BinarySerializer`, `TcpSocket`/`TcpServer`.
- **Frozen public API** (ADR-0026): the non-`detail` surface reachable from `util.hpp` is the 1.0
  contract; future changes follow SemVer.
- **Quality bar:** warnings-as-errors, `clang-tidy` clean, `clang-format` clean, ASan/UBSan/TSan/
  Valgrind green, a warning-clean Doxygen build, a reproducible benchmark suite, and **≥80% line
  coverage** (93.0% at release).

## Using it

- **Header-only (default):** link `egl-util::egl-util` and `#include <it/d4np/util/util.hpp>`.
- **Compiled tier (opt-in):** link `egl-util::egl-util-static` for the OS-boundary components
  (`StackTrace`, `Logger`, `FileStream`, `TcpSocket`/`TcpServer`); their headers expose only
  declarations, so header-only consumers pay nothing for them.
- **Toolchains:** Linux (GCC ≥ 11, Clang ≥ 14), Windows (MSVC ≥ 19.30), macOS (Apple Clang ≥ 14).

## Compatibility

This 1.0.0 release consolidates the whole pre-1.0 development line (Milestones 1–10) into the
first stable, SemVer-governed public surface; there is no earlier published release it needs to
stay compatible with. From here, additions are MINOR and incompatible changes MAJOR.
