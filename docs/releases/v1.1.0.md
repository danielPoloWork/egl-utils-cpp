# egl-util-cpp v1.1.0

**Date:** 2026-07-05 · **SemVer:** 1.1.0 (MINOR — additive, no breaking changes)

Milestone 11 — **Specification & Assurance Hardening** — the follow-up to the post-1.0
specification review, delivered across seven PRs. This release is documentation- and
assurance-focused; the only new build surface is an opt-in security-fuzzing tier. The 1.0 public
API is unchanged.

## Highlights

- **Error-handling policy (ADR-0029):** the value-or-error convention every component already
  follows, now written down once — including why `std::expected` is not adopted at the C++20 floor.
- **Architecture views:** a C4 Level-3 component diagram (the real internal dependency graph) and a
  per-component contract table (thread-safety, exception-safety, allocation, complexity) for all 25
  components.
- **Distribution & ABI policy (ADR-0030):** one hybrid model (header-only + optional STATIC
  superset); SemVer protects the API/source surface, with no cross-toolchain binary-ABI promise
  (source distribution).
- **Security (ADR-0031):** coverage-guided **libFuzzer harnesses** for the untrusted-input
  components (`JsonParser`, `CliParser`, `BinaryDeserializer`) under ASan/UBSan, a **threat model**,
  and the hash functions scoped **non-cryptographic** — with extended NIST FIPS 180-4 SHA-256 test
  vectors (empty, `abc`, the 56-byte two-block, and the one-million-`'a'` messages).
- **Performance targets:** the benchmark baselines are now documented numeric targets —
  machine-independent algorithmic-class invariants plus relative regression thresholds.
- **Spec reconciliation:** the §5 `FlatMap::find` wording now matches the shipped iterator API, with
  a compile-verified constexpr example.

## New build surface

- `EGL_UTIL_BUILD_FUZZERS` (default ON at top level, **standalone replay** mode) and a `fuzz`
  CMake preset (Clang + libFuzzer) that builds the coverage-guided harnesses. Header-only consumers
  are unaffected; the default header-only contract is unchanged.

## Using it

- **Header-only (default):** link `egl-util::egl-util` and `#include <it/d4np/util/util.hpp>`.
- **Compiled tier (opt-in):** link `egl-util::egl-util-static` for the OS-boundary components.
- **Toolchains:** Linux (GCC ≥ 11, Clang ≥ 14), Windows (MSVC ≥ 19.30), macOS (Apple Clang ≥ 14).

## Compatibility

Fully backward-compatible with v1.0.0: no public symbol was removed, renamed, or changed in
signature or semantics. Upgrading is a drop-in. See [ADR-0030](../adr/0030-abi-stability-policy.md)
for the API/source vs binary-ABI stability contract.
