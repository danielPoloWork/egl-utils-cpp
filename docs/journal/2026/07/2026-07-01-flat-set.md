# 2026-07-01 — FlatSet<T> (roadmap 4.1)

## What got done

- Implemented `it::d4np::util::FlatSet<T, Compare>` (component #15, ADR-0009): an ordered set
  stored as a single sorted, contiguous `std::vector`. O(log n) binary-search lookup
  (`find`/`contains`/`count`/`lower_bound`/`upper_bound`), unique insertion, O(n) `insert`/
  `erase`. Initializer-list / range / comparator constructors; `reserve`/`capacity`/`clear`;
  const-only iterators (elements are immutable to preserve the sort invariant). Added to the
  umbrella header.
- Opened Milestone 4 with ADR-0009, which adopts the **flat (sorted-contiguous)** model for
  the whole associative-container set — cache locality and compact footprint over node-based
  trees, mirroring C++23 `std::flat_set` (which the C++20 baseline can't yet require). FlatMap
  (4.2) and CircularBuffer (4.3) will reference it.

## clang-tidy notes
