# 2026-07-01 — FlatMap<Key,Value> (roadmap 4.2)

## What got done

- Implemented `it::d4np::util::FlatMap<Key, Value, Compare>` (component #14, ADR-0009 +
  ADR-0010): an ordered map stored as a single sorted, contiguous `std::vector` of pairs.
  O(log n) `find`/`contains`/`count`/`at`/`lower_bound`/`upper_bound`; `insert` (with a
  `(key, value)` convenience overload), `operator[]`, `erase` by key and iterator; const-only
  iterators; comparator type parameter. Added to the umbrella header.
- **Full `constexpr` support** (the roadmap's headline requirement for this component):
  - Every method is `constexpr`. A `FlatMap` can be built and queried inside a constant
    expression (proven by `static_assert` tests, incl. `operator[]` insert-then-update).
  - Construction branches on `std::is_constant_evaluated()`: `std::stable_sort` + `std::unique`
    at runtime (O(n log n)), sorted `insert` during constant evaluation (`std::sort` isn't
    `constexpr` before C++26). Documented in ADR-0010.
  - Stores `std::pair<Key, Value>` (non-const key, required for shift-based flat storage);
    key immutability is enforced by exposing only const iterators.

## clang-tidy notes

- `modernize-use-nodiscard` on the private comparator-adapter helpers; and
  `cppcoreguidelines-pro-bounds-pointer-arithmetic` on `++first` in the constexpr build loop
  when `InputIt` is a raw pointer (initializer_list) — switched to `std::for_each` (constexpr in
  C++20) so the increment lives in the stdlib, not user code. See [[local-verify-toolchain]].
